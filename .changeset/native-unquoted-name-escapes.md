An unquoted `font-family` or `font` name stays whole on iOS, Android, and React Native for Web. A name holding a CSS escape reads as a browser reads it, so `A\42 B` names the face `ABB` and `\73 erif` is the generic keyword `serif`. A name starting with a hyphen, such as `-apple-system`, is one name, and a `font` declaration holding one keeps its size and weight. A keyword the library matches, such as `\62 old` in `font`, reads correctly too. A value that reaches React Native as text, such as the color in `color: r\65 d` or `border: 1px solid r\65 d`, keeps the escape as written and isn't read as `red`, and an escape inside a unit (`10\70 x`) isn't read. A vendor-prefixed name in a transition, such as `transition-property: -webkit-transform, opacity`, reads as `transform` at its place in the list. A sign belongs on a number inside math, as in a browser, so `calc(-pi * 1px)` holds the name `-pi` and warns in development, while `calc(-1 * pi * 1px)` resolves.
